# 舆情分析智能体系统

一个基于 AI 技术的智能舆情分析系统，提供报告生成、咨询对话、信息检索三大核心功能。

## 系统功能

### 1. 智能报告生成

- 支持预设大纲和自定义大纲两种模式
- 智能分析事件起因、事件分析、建议措施
- 可自定义每节的具体要求
- 支持历史报告保存和管理

### 2. 舆情咨询对话

- 多轮对话分析舆情事件
- 智能问答和深度分析
- 支持上下文理解和连续对话

### 3. 舆情检索系统 ⭐ **新增功能**

- **多维度检索**：支持标题、内容关键词、主题分类、来源、话题、情感、地域等多重筛选
- **新闻来源丰富**：人民日报、环球时报、腾讯新闻、网易新闻、新浪新闻等主流媒体
- **话题聚类**：自动将相同事件的新闻归为一类，给定统一话题词
- **情感分析**：自动识别新闻情感倾向（正面/负面/中性）
- **地域分布**：支持按地域筛选和分析
- **话题大屏**：点击话题词可查看详细的数据分析和可视化展示

## 舆情检索功能详解

### 检索条件

- **关键词搜索**：支持标题、内容、关键词的模糊搜索
- **分类筛选**：科技、政策、环保、教育、健康、经济、文化、体育、社会、国际
- **来源筛选**：人民日报、科技日报、经济日报、教育周刊、健康报、环保时报、文化报、体育报、社会观察、国际新闻、环球时报、腾讯新闻、网易新闻、新浪新闻
- **话题筛选**：科技创新、政策改革、环保行动、教育发展、健康生活、经济稳定、文化传承、体育竞技、社会进步、国际合作
- **情感筛选**：正面、负面、中性
- **地域筛选**：北京、上海、广东、江苏、浙江、山东、河南、四川、湖北、湖南
- **时间范围**：支持开始日期和结束日期筛选

### 新闻展示

每条新闻包含以下信息：

- 新闻标题
- 主题分类标签
- 话题标签（可点击跳转到大屏分析）
- 摘要内容
- 来源媒体
- 发布时间
- 情感倾向（带表情符号）
- 关键词标签
- 原文链接

### 话题分析大屏

点击新闻中的话题标签，可跳转到专门的话题分析页面，包含：

#### 核心指标

- **新闻总数**：该话题下的新闻数量
- **事件跨度**：话题持续的时间范围
- **总参与度**：所有新闻的参与度总和
- **情感分布**：正面、负面、中性新闻的百分比

#### 可视化图表

- **话题热度趋势**：30 天内的新闻发布趋势和情感变化
- **情感分析**：正面、负面、中性情感的详细分布
- **来源分布**：各媒体来源的新闻数量和占比
- **地域分布**：各地区新闻数量和占比
- **关键词云**：相关关键词的频率和权重展示

## 技术架构

### 前端

- React 18 + TypeScript
- React Router 用于路由管理
- 响应式设计，支持移动端
- 现代化 UI 设计，采用卡片式布局

### 后端

- FastAPI (Python)
- 支持异步处理
- RESTful API 设计
- 模拟数据生成（开发阶段）

### 数据模型

```typescript
type NewsItem = {
  id: string;
  title: string;
  content: string;
  source: string;
  url: string;
  publishedAt: string;
  category: string;
  keywords: string[];
  topic: string; // 话题聚类
  sentiment: string; // 情感分析
  region: string; // 地域信息
  engagement: number; // 参与度
};
```

## 快速开始

### 环境要求

- Python 3.8+
- uv (Python 包管理器)
- Node.js 16+
- npm 或 yarn

### 安装依赖

#### 后端

```bash
cd backend
uv sync
```

#### 前端

```bash
cd frontend
npm install
```

### 启动服务

#### 后端服务

```bash
cd backend
.venv\Scripts\Activate.ps1
uv run python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

#### 前端服务

```bash
cd frontend
npm run dev
```

### 访问系统

- 前端：http://localhost:5173
- 后端 API：http://localhost:8000
- API 文档：http://localhost:8000/docs

## 使用流程

### 舆情检索

1. 进入"舆情检索"页面
2. 设置检索条件（关键词、分类、来源、话题、情感、地域、时间）
3. 查看检索结果
4. 点击话题标签查看详细分析
5. 点击"查看原文"访问原始新闻

### 话题分析

1. 在新闻列表中点击话题标签
2. 查看话题的统计数据和趋势分析
3. 分析情感分布和地域分布
4. 查看关键词云和热度趋势
